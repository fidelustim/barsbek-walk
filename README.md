# Барсбек гуляет

Прототип: управляешь персонажем от третьего лица в 3D-локациях прямо в браузере.

- Three.js — рендер, Spark — гауссовы сплаты (сканы Scaniverse/Polycam/Luma), Rapier — физика.
- Локации описаны в `locations/locations.json` (типы `procedural` и `splat`).
- Свой скан можно открыть кнопкой в меню — файл читается локально, никуда не загружается.

Управление: WASD, Shift — бег, Пробел — прыжок, мышь — обзор, V — вид от первого лица, Esc — меню.
Отладка: C — показать стены, N — сквозь стены, U — сменить «верх» скана, [ ] — сдвиг пола, H — статистика.

Временная модель персонажа: RobotExpressive by Tomás Laulhé (Quaternius), CC0.
